# c_mend3 method cost and reserve limits — 2026-10-12

The official VM probe confirms that the safe-healing fallback can select a second island, with unchanged cost on
the tested safe-nearest path. It also confirms that the fallback's 6,000-bytecode loop guard is **not a return
floor**: three tested calls returned below it, down to 5,912. This is method evidence, not proof of full-turn safety,
live firing frequency, healing delivery or improved strength. Keep c_mend2 validated pending those measurements.

## Evidence and provenance

The zero-game probe ran with the checksum-pinned official 3.0.15 engine and VM JDK 8u504, using only our frozen
c_mend2 (`d62033781fbd`) and c_mend3 (`db9f54f47fea`) source in private class trees. It used the engine's
`TeamClassLoaderFactory`; no opponent source, game, ladder submission or shared bot build was involved.

Driver artifacts: `build/codex-recovery/mend-probe-20261012T213328Z/`, including owned probe source, `result.json`
and `provenance.json`. Result SHA-256:
`5b6884e61ba13d996d6b2b31dda1e149e5ec6a4d4cca47c3ded5c3ba7fa01c51`.
Engine SHA-256: `5d4e42a51946cc1c2149426485bda8096ff1c088c77e3ed075c06ce5968ed72a`.

The interval is `mendUpdate` itself. Costs include instrumented own instructions, array accounting and API
call-site charges; host setup, proxy bodies, class initialization and the later turn tail are excluded. Separately
calibrated shared-read/map/health/island-count wrappers cost 5/8/3/22, including their wrapper instructions. Every
method return had zero pending bytecode debt. Initialization is recorded separately (644 in these fixtures).

There are 117 cases: nine fixed island/sighting shapes at thirteen real method-entry budgets from 5,999 to 10,000,
including 6,000, 7,499 and 7,500. Each measurement was repeated in a fresh loader: zero repeat differences and zero
common-path decision differences. Eighteen candidate calls entered the fallback. These are synthetic fixture
counts, not observed live opportunity rates. Exact shared slots, coordinates, read traces, decisions and remaining
budgets are in the artifact. The independent official run matched the explicitly marked local prototype.

## Why the guard is not a floor

**A 7,500 method-entry budget is not a 7,500 fallback-entry budget.** Health checking, the original nearest-island
scan and the first enemy-sighting check run before the fallback admission check. The fallback requires no visible
enemies and at least 7,500 remaining at that later point. The original scan retains its existing 3,000 loop guard;
the 7,500-entry dense fixture returns near 5,100 without entering the fallback in either build.

The fallback checks for 6,000 before each island iteration. An admitted iteration and the final assignment/return
still cost bytecodes, producing these official crossings:

| Fixture | Entry budget | Last fallback shared-read effective left | Method return left |
|---|---:|---:|---:|
| 35 owned, four sightings | 10,000 | 5,995 | 5,912 |
| 35 mixed ownership, four sightings | 9,500 | 6,003 | 5,971 |
| 35 owned, all blocked | 10,000 | 6,029 | 5,947 |

Read traces and returns have zero pending debt, so these crossings are real counted work, not deferred accounting.
The measured minimum is not a universal worst case. The probe excludes `fight`, `march`, `pickObjective`, movement,
the second shot and telemetry. In particular, `march` chooses an objective before its mend override, and `fight`
has setup before its own guard. Neither this probe nor the logical Mend3 tests establishes a safe full-turn tail.

## Required delivery check

Use fixed own-versus-own candidate/control cells to measure fallback reachability, healing and the remaining turn
tail before spending field games. Preserve frozen source/class hashes, map, side and seed. Check native profiler
on/off state and bytecode fingerprints on an identical control, and disclose the profiler's 2,000,000-event team
cap if coverage truncates. Existing local telemetry can show mending objectives, work before the fill, exceptions
and near misses; replay extraction supplies healing, movement, shots and overruns. It does not by itself prove
which shared-sighting fallback selected a target. If that distinction needs diagnostic hooks, measure their cost
with matched controls; logging near a guard can change the decision. Two diagnostic cells establish neither a
field effect nor a statistical acceptance verdict.
