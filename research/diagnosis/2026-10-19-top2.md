## Summary

1. **Basics fail first (CLAUDE.md rule 9).** Our units get stuck in two ways.
   - **Sealed spawn pockets.** The HQ spawns units on tiles that are cut off.
     - On Jail (9900 g0, a loss), 2 of our carriers built at r2 stood in a 2-tile pocket for 162 and 172 turns.
     - On ThirtyFive (9918 g2, a win), 3 of our 4 opening launchers stood in pockets for all 893 turns.
     - `HQ.tryBuild` (HQ.java:207-213) has no reachability test (`synth_v5_basics.py`).
   - **A frozen carrier**, separately. Two carriers held still 4-5 tiles from an Ad well for 412-442 rounds and never collected, although `unjam()` exists:
     - PairedProgramming 9913 g1, a loss;
     - Forest 9929 g0, a win.
     - The cause is not located.
2. **Mechanism 1: we lose our home economy by r150 because we have fewer launchers.** This covers 17 of 31 losses (class A, 16 distinct).
   - **Our carriers die at home.** Up to r100 our carriers died 105 times against their 17.
     - 76 of those deaths were within d² 64 of our HQ.
     - 65 were at a mana well that `frontGate` calls home, which can never turn hot (`synth_v1_carriers.py 100`).
   - **Mana binds, not adamantium.** Over r101-250 we built 210 launchers against their 407 (`synth_v2_binding.py`).
   - **At their home carrier deaths our army is mostly dead, not away.** Over the 194 deaths in A: median launchers alive 4, near the death 1, against their 6; the army was elsewhere in only 0.17 of them (`synth_v6_home.py`).
   - **We lose the launchers at parity.** Our launchers that die by r150 die at a median of 2.5 against 2, and outnumbered 0.32 of the time. Theirs die at 4 against 1, outnumbered 0.11. In wins both sides die at 3 against 1 (`synth_v7_front.py`).
3. **Mechanism 2: we lose the first launcher war at parity, with no carrier gap.** This covers 5 of 31 losses (A0): TimesUp, Contraction, BatSignal, Clown, Marsh.
   - Our launchers that die by r150 die at 2 against 2, outnumbered 0.34; theirs die at 5 against 1.5 (`synth_v7_front.py`).
   - TimesUp and Marsh then end on the r2000 tiebreak.
4. **Mechanism 3: midgame and islands.** This covers 9 of 31 losses (B 5, C 4), plus the tiebreak tail of TimesUp and Marsh.
   - They first hold an island at a median of r300; we first hold one at r470 in BC (`synth_v4_islands.py`).
   - In BC the anchor gate (HQ.java:68) is closed by the island deficit on 0.73 of samples; on TimesUp, on 105 of 110.
5. **The siege-spawn feeding the analysts flagged is a consequence, not a cause.**
   - In A, 532 of 948 launchers were born at a besieged HQ, with a median life of 4.
   - In wins, 1 of 3696 was (`synth_v3_launchers.py`).
   - c_siege1 already failed (panel net -3). I propose no change for it.
6. **Refuted, or not to be re-proposed:**
   - **"The army does not come home" as a general cause.** Its share is 0.17 (`synth_v6_home.py`).
   - **An earlier ANCHOR_START.** c_ec09 measured +3 for moving it from 250 to 400.
   - **Ad economy levers.** Analyst 3 estimates 0 flips.
   - **"The flee-and-return loop" as the discriminating pattern.** It ends 20 of the 33 fatal trips in wins (R150) too.
   - **Blind and cloud fire** is confirmed (0.86 against 0.33 fire share) but is worth only 0.04 launcher hits per cloud turn. c_blind1 and c_blind2 were rejected, and c_kx0 has no switch for it.
7. **Ranked changes** (each a new C.java constant whose default reproduces c_eco3):
   1. SPAWN_POCKET (basics);

   3. CENTRE_SKIP_R2 (SoundWave);

### 1. SPAWN_POCKET: never spawn into a sealed pocket (basics, rule 9)

**C.java** (after line 140, `UNJAM_TURNS`), add:

```java
 *  counts as an exit) has at most SPAWN_POCKET tiles. 0 = c_eco3. diag-top2: Jail (4,19)/(5,19), ThirtyFive. */
public static final int SPAWN_POCKET = 0;   // proposed 4
```

**HQ.java:212**

Before:

```java

```

After:

```java

```

Then add a method to HQ. It is run lazily, only for a tile that would become the best, and its result is cached because walls never change:

```java
static byte[] pocket;   // per spawn tile: 0 unknown, 1 open, 2 sealed
static boolean sealed(int i) throws GameActionException {
    if (pocket == null) pocket = new byte[spawnTiles.length];
    if (pocket[i] != 0) return pocket[i] == 2;
    RobotController rc = G.rc;
    MapLocation[] q = new MapLocation[C.SPAWN_POCKET + 2];
    q[0] = spawnTiles[i];
    int n = 1;
    boolean open = rc.senseMapInfo(q[0]).getCurrentDirection() != Direction.CENTER;
    for (int h = 0; h < n && !open; h++) {
        for (int k = 8; --k >= 0 && !open; ) {
            MapLocation x = q[h].add(G.DIRS[k]);
            if (!rc.onTheMap(x)) continue;
            boolean seen = false;
            for (int j = n; --j >= 0; ) if (q[j].equals(x)) { seen = true; break; }
            if (seen) continue;
            if (!rc.canSenseLocation(x)) { open = true; break; }
            if (!rc.sensePassability(x)) continue;
            RobotInfo r = rc.senseRobotAtLocation(x);
            if (r != null && r.type == RobotType.HEADQUARTERS) continue;
            if (rc.senseMapInfo(x).getCurrentDirection() != Direction.CENTER || n > C.SPAWN_POCKET) { open = true; break; }
            q[n++] = x;
        }
    }
    pocket[i] = (byte) (open ? 1 : 2);
    return !open;
}
```

When only sealed tiles can take a build, `best` stays null, `tileFail` is set and the resources are kept.

**Expected re-dump effects** (`synth_v5_basics.py`):
- Our sealed-pocket units go from 5 to 0: Jail 2 carriers, ThirtyFive 3 launchers.
- Jail Mn by r100 rises from 30 (`synth_v8_centre.py`).
- ThirtyFive fields 3 more opening launchers.
- On Jail's 24-tile HQ enclosure and Pipes' 27-tile one, nothing changes: both exceed SPAWN_POCKET and exit by currents.

**Games expected to flip:** 0-1 (Jail, 9900 g0, class A). The ThirtyFive win is kept with more launchers.

**Risks to our wins:**
- A tile wrongly judged sealed only moves a spawn to the next-best tile.
- Unsensed tiles count as exits, so the test is conservative.
- No RNG is drawn.

**Bytecode cost:**
- About 250-500 per open tile evaluated: it exits after SPAWN_POCKET+1 tiles.
- Up to about 3,000 per sealed tile, once, because the result is cached.
- The HQ has 20,000, and tryBuild's 3,500 guard stays.

**Judge:** self-play against c_eco3 can judge it. The effect is map geometry: Jail, ThirtyFive and Clown, played from both sides. Then a unit test of `sealed()` against those three maps.

**Prior attempts:** none. ATTEMPTS has c_line8b (spawn tile away from enemies) and c_nav3 (navigation out of dead-end pockets), but nothing about spawn reachability.
